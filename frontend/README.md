## 1. Project Architecture

```
Forcaster-orgy/
├── backend-ai/               ← Python: ML pipeline + FastAPI server
│   ├── api_server.py         ← FastAPI server (port 4000) — serves the frontend
│   ├── main.py               ← ML pipeline orchestrator (run once to generate forecast.db)
│   ├── m1_data_preparation.py
│   ├── m2_model_assignment.py
│   ├── m3_kpis.py
│   ├── m4_sarima.py
│   ├── m5_catboost.py
│   ├── m6_size_curves.py
│   ├── m7_recommendations.py
│   ├── m8_output.py
│   ├── database.py           ← SQLite layer (populates forecast.db)
│   ├── config.py             ← All tunable settings (column names, model params, etc.)
│   ├── requirements.txt      ← Python dependencies
│   ├── data/
│   │   ├── raw/
│   │   │   └── THE_FINAL_10Y_cleaned.csv   ← ⚠ NOT in git — required to run pipeline
│   │   └── forecast.db                     ← ⚠ NOT in git — generated by pipeline
│   └── output/               ← CSV outputs written by the pipeline
├── frontend/                 ← Next.js 14 dashboard
│   └── src/
└── .venv/                    ← Python virtual environment (lives at repo root)
```

**Data flow:**

```
THE_FINAL_10Y_cleaned.csv
        ↓
  python main.py   (ML pipeline: ~minutes)
        ↓
  forecast.db  +  output/*.csv
        ↓
  python api_server.py  (FastAPI on :4000)
        ↓
  npm run dev  (Next.js on :3000)
```

## 3. Clone & Data Files

```bash
git clone https://github.com/airotix/forecaster-orgy.git
cd forecaster-orgy
```

**Data files are not in the repository** (they are excluded by `.gitignore` because of their size). You must place them manually:

| File | Location |
|------|----------|
| `THE_FINAL_10Y_cleaned.csv` | `backend-ai/data/raw/THE_FINAL_10Y_cleaned.csv` |
| `forecast.db` *(optional — see §5)* | `backend-ai/data/forecast.db` |

If you have a pre-built `forecast.db`, you can skip Step 5 and go straight to running the API.

## 4. Python Environment Setup

The virtual environment lives at the **repo root** (`.venv/`).

### Windows (PowerShell)

```powershell
# From repo root
python -m venv .venv
.venv\Scripts\Activate.ps1

# Install all Python dependencies
pip install -r backend-ai/requirements.txt
```

### Mac / Linux

```bash
# From repo root
python3 -m venv .venv
source .venv/bin/activate

# Install all Python dependencies
pip install -r backend-ai/requirements.txt
```

**What gets installed** (from `backend-ai/requirements.txt`):

| Package | Purpose |
|---------|---------|
| `pandas`, `numpy` | Data manipulation |
| `pmdarima`, `statsmodels` | SARIMA forecasting |
| `catboost`, `scikit-learn` | ML forecasting |
| `shap` | Model explainability |
| `openpyxl` | Excel output |
| `fastapi`, `uvicorn[standard]` | API server |

> ⚠ The `catboost` install can take a few minutes — this is normal.

## 5. Run the ML Pipeline

> **Skip this step** if you already have a `forecast.db` file to place in `backend-ai/data/`.

The pipeline reads the raw CSV, runs SARIMA + CatBoost models across all SKUs, and writes results to `forecast.db` and `backend-ai/output/`.

```powershell
# Make sure your .venv is activated (see Step 4)
cd backend-ai
python main.py
```

Expected output:

```
╔══════════════════════════════════════════════════════════╗
║  AI-DRIVEN ORDER PLANNING — PHASE 1 EXECUTION          ║
║  SARIMA + CatBoost Forecasting Pipeline                 ║
╚══════════════════════════════════════════════════════════╝
...
╔══════════════════════════════════════════════════════════╗
║  PHASE 1 COMPLETE — XX.X seconds                        ║
╚══════════════════════════════════════════════════════════╝
```

**Files produced:**

| Output | Location |
|--------|----------|
| Main database | `backend-ai/data/forecast.db` |
| Monthly forecast detail | `backend-ai/output/forecast_monthly_detail.csv` |
| Order recommendations | `backend-ai/output/recommendations.csv` |
| SKU summary | `backend-ai/output/summary_by_sku.csv` |

**Optional: use a different data file**

```bash
python main.py --data path/to/your/file.csv
```

## 6. Run the Backend API

The FastAPI server reads `forecast.db` and serves all endpoints the frontend needs. It runs on **port 4000**.

```powershell
# From backend-ai/ with .venv activated
cd backend-ai
python api_server.py
```

You should see:

```
INFO:     Started server process
INFO:     Uvicorn running on http://0.0.0.0:4000 (Press CTRL+C to quit)
```

Verify it's working:

```
http://localhost:4000/docs          ← Interactive API docs (Swagger UI)
http://localhost:4000/health        ← Health check
http://localhost:4000/api/articles?season=SS2025
```

**Key API endpoints:**

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/articles` | Filtered article/forecast data |
| GET | `/api/filter-options` | Filter dropdown values for a season |
| GET | `/api/customers` | Customer list |
| GET | `/api/customer-detail` | Detail for a specific customer |
| GET | `/health` | Service health check |

Valid season values: `SS2024`, `FW2024`, `SS2025`, `FW2025`

## 9. Environment Variables

### Backend (`api_server.py`)

The server port is hardcoded to `4000` in `api_server.py`. To change it, edit the last line:

```python
uvicorn.run("api_server:app", host="0.0.0.0", port=4000, reload=True)
```

### Frontend

Create `frontend/.env.local` to override the backend URL:

```env
NEXT_PUBLIC_API_URL=http://localhost:4000/api
```

This is the default — only needed if you change the backend port or deploy remotely.

## 11. Troubleshooting

### `forecast.db not found` or API returns empty data

The pipeline has not been run yet, or `forecast.db` is missing. Either:
- Run `python main.py` in `backend-ai/` (see §5), or
- Copy your `forecast.db` to `backend-ai/data/forecast.db`

### `THE_FINAL_10Y_cleaned.csv not found`

Place the file at `backend-ai/data/raw/THE_FINAL_10Y_cleaned.csv` before running the pipeline.  
To use a different filename, update `DATA_FILE_NAME` in `backend-ai/config.py`.

### Frontend shows no data / API errors in browser console

- Confirm the backend is running: visit `http://localhost:4000/health`
- Confirm the backend is on port 4000 (or set `NEXT_PUBLIC_API_URL` in `frontend/.env.local`)
- Check the browser Network tab for the failing request URL

### `pip install` fails on `catboost`

CatBoost requires a C++ compiler on some systems:
- **Windows**: Install [Visual C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
- **Mac**: Run `xcode-select --install`
- **Linux**: Run `sudo apt install build-essential`

### Python `ModuleNotFoundError`

Make sure your virtual environment is activated before running any Python command:
```powershell
.venv\Scripts\Activate.ps1   # Windows
source .venv/bin/activate    # Mac/Linux
```

### `npm install` fails or `node_modules` is corrupt

```powershell
# In frontend/ or backend-ai/
Remove-Item -Recurse -Force node_modules
npm install
```

### Port already in use

- Backend port 4000: find and kill the process with `netstat -ano | findstr :4000` (Windows)
- Frontend port 3000: Next.js will automatically try port 3001 if 3000 is occupied
